# What each demo task does, and when (docs/demo/README.md). The stand-in
# agent (docs/demo/claude) runs the script of the first entry whose words
# the task contains; "*" matches any task. An entry is "words | script",
# and indented lines carry its script on.
#
# Steps are the fakeagent's (internal/testutil/fakeagent): prompt, tool:NAME,
# ask (a question), permission (Bash wants to run rm -rf build), stop and
# sleep:DURATION. ask and permission wait until a line is typed into the
# agent's terminal. (steps) * N repeats steps N times.
#
# The tools here take no file path, so no sandbox path reaches the
# sidebar's detail line.
