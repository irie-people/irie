# Phrasebook

Date: 2026-10-26. Read with [AGENTS.md](../AGENTS.md) and the site's writing rules in [proposals/site.md](proposals/site.md).

These are Irie's fixed lines. Pages and docs use them word for word: the same words, in the same order, with the same punctuation. Only the typography follows the medium: HTML pages set apostrophes and quotes as ’ “ ”, and Markdown files as ' and ".

- **Use a line as it is, or leave it out.** Don't shorten it, merge it with another or reword it for one page.
- **Explain next to a line, not inside it.** The sentences around a line may suit their readers; the line itself stays put.
- **Don't coin new slogans.** If a page needs a line that is not here, propose it in an issue first.
- **Change a line everywhere at once.** Change it here and in every place its "Used in" names, in the same change. `grep -rn` with a few of its words finds them.
