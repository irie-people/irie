Roadmap

Irie is built one milestone at a time, and version 1 is all eleven. The full plan is in the design document.

Version 1

  1. 1

    Launch and look Done

    Open Irie and type a task, and Claude Code starts on it. Press Enter on its row to watch it work, and close the window without stopping it.

  2. 2

    Live states Done

    Rows show who is working, who needs you, who is done and which task couldn’t start. Most of it comes from Claude Code’s hooks, small commands it runs as it works.

  3. 3

    Repos, worktrees, any task size, profiles Done

    Name a project, or repo, with @, and its agent gets a worktree of its own: a second working copy, so agents keep out of each other’s way.

    Pick the agent and the AI model for each task with + and a profile, a recipe you name. Any agent that runs in a terminal, the window where you type commands, can be started.

    Tasks of any size can be pasted in.

  4. 4

    Manage the list Next

    Park rows out of the way, rename them, jump to one by typing, and close and reopen them. Undo and redo any of it.

  5. 5

    Pause at the next tool call Planned

    Pause an agent at its next tool call, a step such as running a command or editing a file. Let it go when you’re ready, and it’s told how long it waited.

  6. 6

    Freeze Planned

    Stop an agent and everything it started, at once. Thaw it and it carries on; if it was busy, it’s told it was frozen.

  7. 7

    Priority and notes Planned

    Mark a task as urgent: it moves to the top, and its agent is told to focus. Send any agent a note, which it reads at its next step.

  8. 8

    Subagent panes Planned

    Some agents start helpers, called subagents, for parts of a task. Each gets a live view, or pane, of its own, and you can pause one alone.

  9. 9

    The Irie window in Ghostty, and Irie.app Planned

    On a Mac, find Irie in Spotlight, the Mac’s search, and open it like any app. It opens in a window of Ghostty, a free terminal app, and opening it again brings that window forward.

  10. 10

    Local models: context preflight Planned

    Before an agent starts on a model on your own computer, Irie checks that the model can hold enough text for an agent’s work. If it can’t, Irie says how to fix it.

  11. 11

    Control-mode events and real-Claude smoke tests Planned

    tmux, which keeps the agents running, tells Irie about changes at once instead of being asked every second. A set of tests runs against the real Claude Code.

After version 1

  1. Fuller support for more agents: Codex CLI first, then opencode, Gemini CLI and pi, then goose, hermes-agent, Amp and crush.
  2. Choosing a model for each task by cost and limits, and agents working together, such as a review by another company’s model.
  3. Popping an agent out into its own Ghostty tab.
  4. Seeing which agents work on the same project and how near each is to the most its model can hold in mind, and a focus mode that pauses the rest.
  5. Cost tracking, clearing out old worktrees, and a desktop alert when an agent needs you.

Irie is free, and anyone may read, change and share its code under the Apache 2.0 license.

If it ever makes money, it goes back to the people who build it, after running costs: see how.
