Install

You paste one line into a terminal, the window where you type commands. On a Mac, that is the Terminal app: press ⌘Space, type Terminal, and press Return.

Install it with one line

curl -fsSL https://irie-people.github.io/irie/install.sh | sh

It works on a Mac or a Linux computer, with an Apple silicon, Intel or ARM processor. Windows isn’t planned for version 1. The line:

  1. downloads the latest release of Irie for your computer from GitHub, and checks the download against the SHA-256, a fingerprint, that the release lists for it, so a file that was changed is refused;
  2. puts the irie program in ~/.local/share/irie/bin, with a link in ~/.local/bin, where Claude Code’s own installer puts claude too;
  3. on a Mac with Apple silicon, puts Irie.app in ~/Applications, where Spotlight finds it;
  4. runs irie setup, which checks what else Irie needs, and offers to install each part that is missing.

Nothing is installed without a yes, and nothing changes outside those folders, apart from one line irie setup may offer to add to your shell’s startup file. The installer is a short script you can read first. IRIE_VERSION=0.2.0 in front of sh installs a release other than the latest.

If a release has no download for your computer, the line builds Irie from its source code instead, which needs Go: see Build it from source.

What Irie needs

irie setup checks each of these and says how it stands, in plain words. For each one that is missing, it says what it would run, and runs it only after a yes. Run it again whenever you like.

  • tmux, which keeps your agents running when no window is open: 3.2 or later. Irie is written against tmux 3.7b. On a Mac, irie setup installs it with Homebrew, and installs Homebrew first on a Mac without it, which asks for your password. On Linux it uses your package manager: apt, dnf, yum, pacman, zypper or apk.
  • Claude Code, the coding agent Irie starts for you, from its official installer.
  • Claude Code signed in to your own account: irie setup runs claude auth login, which opens your browser. An API key in ANTHROPIC_API_KEY counts too.
  • git, which gives each task on a project its own worktree. Only tasks on a project need it. On a Mac it comes with Apple’s Command Line Tools, which irie setup offers to install.
  • irie on your PATH, the list of folders a terminal looks in for programs, so that typing irie works. irie setup offers to add ~/.local/bin to it, in your shell’s startup file.

By default Irie asks Claude Code for Opus 5.5 at max effort in auto mode, so your account must allow them. You can change each one in a profile.

irie setup --check only checks, and changes nothing. irie setup --json prints the check for a script, and both end with an error when agents can’t start yet.

Open it

On a Mac, open Irie from Spotlight: press ⌘Space, type Irie, and press Return. The app starts Irie by itself, with the PATH and settings your terminal would have, so agents find claude, git and whatever else you installed. Its welcome lists what Irie needs, with a button on anything missing, and offers a first task to try: Your first session.

In a terminal, type:

irie

The first time, Irie checks that it has what it needs, as irie setup does, and offers to fix what is missing. Then it sets itself up and opens in the same terminal window:

  1. It makes its folders: ~/.local/state/irie for its own records, and ~/.local/share/irie for the folders agents work in. Only you can read them.
  2. It writes a tmux settings file of its own. Your own tmux settings are never read or changed.
  3. It starts a tmux of its own, named irie, apart from any tmux you already use. Inside it runs Irie’s core: the part that starts agents and keeps track of them.
  4. The core draws the list on the left and the space for an agent on the right, and your terminal joins in. With no tasks yet, the right side welcomes you with a first task to try.

Irie doesn’t make a settings file. Until you write one, it uses its defaults, which irie config print shows and Profiles and models lists.

Next time, irie joins the Irie that’s already running, with every agent where you left it. If you set the XDG_CONFIG_HOME, XDG_STATE_HOME or XDG_DATA_HOME folders, Irie uses them instead, on a Mac too.

Your first session shows what you’ll see, and what to type.

Inside tmux already?

Run inside another tmux, irie stops and says so. irie attach --nested opens it there anyway.

Without a window

irie up starts Irie in the background and comes straight back. irie ctl spawn does it for you, so a script can start agents with no window open: see Keys and commands. irie up --login-env starts it with your login shell’s settings, as the Mac app does.

Update it

Run the same line again:

curl -fsSL https://irie-people.github.io/irie/install.sh | sh

It puts the new irie in place of the old one in one step, and reopens Irie.app if it was open. The next irie sees the new build and restarts Irie’s own parts with it. Your agents keep running.

Keep irie where it is

Each running agent reports to Irie through irie, by the path it had when the agent started. Don’t move or delete it while agents run: their reports would fail, and Claude Code 2.1.295 and later then block their steps.

Updating it in place, with the installer or a new build, is fine.

Build it from source

To build Irie yourself from its source code, the files it is written in, you need Go 1.26 or later, the programming language Irie is written in (go.dev/doc/install), and git.

git clone https://github.com/irie-people/irie
cd irie
go install ./cmd/irie
irie setup

go install puts the irie program in Go’s folder for programs: ~/go/bin, unless you changed it. irie version prints a line such as irie 0.2.0+3f2a9c41d07e; the part after the + is different for every build. If the terminal can’t find irie, add Go’s folder to your PATH: put this line in your shell’s startup file, such as ~/.zshrc on a Mac or ~/.bashrc on Linux, then open a new terminal:

export PATH="$PATH:$(go env GOPATH)/bin"

To update it, run git pull and go install ./cmd/irie again in the same folder. mac/build.sh builds Irie.app, with Apple’s Command Line Tools; docs/MAC.md says how.

Remove it

To stop Irie and every agent in it, all at once:

tmux -L irie kill-server

Then delete the program, the app and Irie’s folders:

rm -f ~/.local/bin/irie "$(go env GOPATH 2>/dev/null || echo ~/go)/bin/irie"
rm -rf ~/Applications/Irie.app
rm -rf ~/.config/irie ~/.local/state/irie ~/.local/share/irie

Look before you delete ~/.local/share/irie: its worktrees folder holds your agents’ work. Each worktree is also listed in its project, so remove them with git first, as Tasks, repos and worktrees shows. A line irie setup added to your shell’s startup file comes after the comment # Added by irie setup; it does no harm, and you can delete both.
