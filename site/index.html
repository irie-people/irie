Good, pleasing, at peace. Everything’s all right.

“Everything irie.”

If you could do anything, what would you do first?

Irie runs your AI coding agents side by side, in one calm view.

A coding agent is an AI program that reads, writes and tests code for you.

Irie lets you run several at once, and shows you which one needs you.

See how it works Get started

Irie is early. It installs with one line, on a Mac or Linux: see Install. The roadmap shows what is built so far.

Why Irie

  • Take back your time.

    Hand the grind to a crew of agents working side by side. Spend your hours on the parts only you can do.

    Builtseveral agents at once, each in its own copy of your project

  • Power to the people.

    Your workflow shouldn’t belong to one AI company. Irie is made to work with agents from any company, so if one raises its prices or goes away, you swap it out.

    Builtother agents too, though Irie sees only whether they’re still running

    Plannedfuller support for other agents: after version 1

  • Local when you can.

    A model, the AI behind an agent, can run on your own computer for free, with your code staying at home. Let it take the small stuff.

    Builta local model for the tasks you choose

    Planneda check that it can hold enough for an agent’s work: milestone 10

  • Many models, one love.

    A fast local model for the small jobs, and a strong one on an AI company’s servers for the hard ones. Then a second opinion from another company’s model before anything reaches you.

    Builta different model for each task

    Plannedchoosing the model for you, and the second opinion: after version 1
