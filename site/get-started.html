Get started

There’s no release of Irie yet, but you can build it from its source code today: see Install. This page shows the four steps of using it.

What you’ll need

To build and run Irie, you’ll need:

  • A Mac or a Linux computer. Windows isn’t planned for version 1.
  • Two free programs: tmux, which keeps agents running in the background, and git, which keeps the history of your code.
  • Go, the programming language Irie is written in, to build it.
  • A coding agent, an AI program that works on code. Today that means Claude Code, signed in to your own account.
  • By default Irie asks Claude Code for Opus 5.5 at max effort in auto mode, so your account must allow them. Each can be changed in Irie’s settings.
  • A terminal, the window where you type commands. Any will do.

Four steps

  1. Open Irie

    Type irie in a terminal and press Enter. A list appears on the left, with room on the right for the agent you pick.

    On a Mac, you’ll also open it from Spotlight, the Mac’s search, in a window of its own. Planned

  2. Type a task

    Press Tab to reach the task box, type what you want done in plain words, and press Enter. An agent starts on it, and a row appears in the list.

    To have the agent work on one of your projects, start the line with @ and its name, such as @shop, or its folder, such as @~/code/shop. It gets a worktree of its own: a second working copy of the project.

    Otherwise each task gets a new, empty folder of its own.

  3. Watch the colours

    Leave the agents to it. A row turns red when its agent needs you, and shows a green tick when it’s done.

    What each colour means

  4. Look in

    Pick a row with the arrow keys and press Enter to see that agent’s screen, live, and answer it there. Press Ctrl+] to go back to the list.

Reading a spawn line

@shop where
A fresh worktree of your project called shop, on its own branch, or line of changes. Irie finds shop in the folders you list in its settings.
A folder works too, such as @~/code/shop, where ~ is your home folder. A folder that isn’t a project under git is used as it is.
@shop! where, in place
The project’s own folder, without a worktree.
+local who
Use your profile called local: a recipe you name for which agent and which model, the AI itself.
The rest: what
Everything else is the task, kept word for word.

Try it now

Build Irie with Install, then take your first session. The docs cover the rest, from worktrees to scripts.
