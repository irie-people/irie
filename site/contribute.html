Contribute

Irie is free to use. If Irie ever makes money, it all goes back to the people who build it, after running costs.

How to help

  1. For anything bigger than a small fix, open an issue, a discussion on the project’s GitHub page, and agree the approach first.
  2. Sign off each commit, a saved change, with git commit -s. That certifies the Developer Certificate of Origin: you have the right to submit the work under the project’s license.
  3. Say in your pull request, the change you send for review, if an agent wrote part of it. You answer for every line, and AI-generated changes sent without discussion are closed.
  4. Once your change is merged, or added to Irie, a maintainer sizes it in Steak with a label such as steak:3. A maintainer is one of the people who look after Irie, and never sizes their own change.

Your Steak starts once a maintainer vouches for you, usually after your first merged change.

Free, and paid back

Get the value you’d pay for, free, today.

If Irie ever makes money (donations, sponsorships, grants), it all goes back to the people who build it, after running costs, in proportion to the value of what they contributed.

The founder started with zero Steak and earns it the same way as everyone else.

The record is public: irie-hq/stake. It runs on Steak v0.1.0.

House rules

  • Build only from public sources, such as documentation and open-source code whose license allows it. List each one in PROVENANCE.md.
  • Keep personal data out. Examples use alice, /home/alice and example.com.
  • Commit in UTC, the world’s reference time, and sign off: TZ=UTC git commit -s.
  • Irie is written in Go, a programming language. Run go test ./... before you send a change.
