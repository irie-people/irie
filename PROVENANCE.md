## Third-party code

No third-party code is copied into the repository. The demo recordings (docs/demo) run vhs (MIT) and the tools it drives, tmux, git and ffmpeg; none of them is copied or compiled in. These Go modules are compiled into `irie`, fetched by the Go toolchain at the versions pinned in `go.mod` and checked against `go.sum` (`go mod verify`). Bubble Tea, Bubbles, Lip Gloss and TOML are direct dependencies (DESIGN §8.1); the rest come in through them. M2 and M3 add no dependency: M3 runs the user's own `git` for repos and worktrees. M10 makes `golang.org/x/sys`, already compiled in, a direct dependency, and runs the user's own `ollama`; it bundles neither Ollama nor any model.
